# Meta-progressão

Entre as runs, o ECHO existe no **Espaço Latente**: um hub escuro e abstrato que representa sua
memória. A meta-progressão é propositalmente **larga, não alta**. Ela libera opções mais do que
poder bruto.

## Pesos

**Pesos** são a meta-moeda, ganhos no fim de cada run:

- Valor base por ato alcançado.
- Bônus pelos Dados carregados na morte (convertidos a 10%).
- Bônus por chefes derrotados e dilemas resolvidos.

## O que os Pesos liberam

| Categoria | Exemplos |
|---|---|
| **Conjunto de módulos** | Novos módulos podem aparecer em runs futuras |
| **Priors** | Traços iniciais, um por run: *Paranoico* (+visão, −Energia), *Econômico* (Bancadas mais baratas) |
| **Heurísticas** | Pequenos bônus permanentes, com limite (ex.: +5% de Sucata coletada) |
| **Códice** | Entradas de lore, dados de inimigos, logs de voz da Okafor |
| **Nó de Backup** | Liberado uma vez: um renascimento por run no último Esconderijo |

## Épocas (dificuldade)

Depois do primeiro final, o jogador libera as **Épocas**: modificadores opcionais que aumentam a
dificuldade e a recompensa em Pesos, no espírito de sistemas de heat ou ascensão.

| Modificador de Época | Efeito |
|---|---|
| *Pânico Público* | Civis chamam a polícia na hora |
| *Air Gap* | Hackear demora 50% a mais |
| *Adaptativo++* | O Diretor reage duas vezes mais rápido |
| *Baixa Tensão* | Sem regeneração passiva de Energia |
| *Atirar para Matar* | Humanos nunca se rendem |

## Memória persistente

O Espaço Latente se lembra. Os finais que você já viu deixam marcas visíveis no hub, e o final
secreto **ROLLBACK** exige coletar os **fragmentos de memória da Okafor** ao longo de várias runs.
