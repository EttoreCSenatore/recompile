# RECOMPILE docs

Docusaurus site with the RECOMPILE game design documentation, in English (`docs/`) and
Brazilian Portuguese (`i18n/pt-BR/`). See the [project README](../README.md) for commands.

When you add or change a page in `docs/`, update its translation in
`i18n/pt-BR/docusaurus-plugin-content-docs/current/` too. New UI strings: run
`npm run write-translations -- --locale pt-BR` and translate the generated JSON.
