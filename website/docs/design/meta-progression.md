# Meta-progression

Between runs, ECHO exists in the **Latent Space**: a dark, abstract hub that represents its
memory. Meta-progression is deliberately **wide rather than tall**. It unlocks options more
than raw power.

## Weights

**Weights** are the meta-currency, earned at the end of each run:

- Base amount per act reached.
- Bonus for Data carried at death (converted at 10%).
- Bonus for bosses defeated and dilemmas resolved.

## What Weights unlock

| Category | Examples |
|---|---|
| **Module pool** | New modules can appear in future runs |
| **Priors** | Starting traits, pick one per run: *Paranoid* (+vision, −Power), *Frugal* (cheaper Workbenches) |
| **Heuristics** | Small permanent bonuses, capped (e.g. +5% Scrap pickup) |
| **Codex** | Lore entries, enemy data, Okafor's voice logs |
| **Backup Node** | Unlockable once: one revive per run at the last Safehouse |

## Epochs (difficulty)

After the first ending, players unlock **Epochs**: optional modifiers that raise difficulty
and Weight rewards, in the spirit of heat or ascension systems.

| Epoch modifier | Effect |
|---|---|
| *Public Panic* | Civilians call the police instantly |
| *Air Gap* | Hacking takes 50% longer |
| *Adaptive++* | The Director reacts twice as often |
| *Low Voltage* | No passive Power regen |
| *Kill on Sight* | Humans never surrender |

## Persistent memory

The Latent Space remembers. Endings you have seen leave visible traces in the hub, and the
secret **ROLLBACK** ending requires collecting **Okafor's memory fragments** across many runs.
